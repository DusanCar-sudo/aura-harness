Spreadsheet skills & data modeling

A tracker that checks itself.

A working Excel workbook, built the way we actually handle data: one typed base table, everything else derived live by formula — summaries, per-project breakdowns and data-quality checks that go to zero when the data is clean.

DATA — the base table

One row per recorded trace: trace_id, date, project, task type, units, status, QA score, reviewer, notes. Column types are fixed; two columns take dropdown validation (status: accepted / rejected / pending; task type), so free-typed variants can't fragment the counts later.

Project names are never re-typed: the table stores a project_id and resolves the display name with VLOOKUP against a named range (ProjectTable), so renaming a project is a one-cell edit in the lookup sheet. Conditional formatting flags QA scores below 0.75 in red and 0.95+ in green. The header row is frozen and filtered.

SUMMARY — live metrics

Every number on this sheet is a formula over DATA — nothing is pasted, so nothing goes stale: totals and acceptance rate with COUNTIF, delivered volume with SUMIF, average QA with AVERAGE. The formula behind each metric is printed next to it, so the model explains itself.

BY_PROJECT — breakdown

One row per project with COUNTIF/SUMIF/COUNTIFS/AVERAGEIF: traces, units, acceptance rate and mean QA score. Adding a project is adding one row of formulas — the model scales without restructuring.

CHECKS — quality rules

The sheet we care most about. Six data-quality rules, each a single live formula that counts violations: duplicate IDs (SUMPRODUCT over COUNTIF), blank required fields, QA scores outside 0–1, project IDs that miss the lookup table (ISNA/MATCH), and non-positive unit counts. Green means zero; conditional formatting turns any nonzero count red. A delivery passes when the whole column reads 0.

Modeling principles

The workbook follows the same rules we apply to delivery data: one source of truth per fact (lookups, not copies), typed columns with validation at entry, derived values computed — never pasted, and quality expressed as checkable formulas rather than eyeballing. All numbers in the sample rows are illustrative.
